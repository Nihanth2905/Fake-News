# Fake News Detection

A Python machine-learning project for classifying news as fake or real using TF-IDF features and multiple classifiers.

## Project layout

- `data/`: input and processed CSV datasets
- `src/`: preprocessing, feature extraction, models, training, evaluation, visualization, and prediction code
- `models/`: saved model artifacts generated by training
- `reports/`: evaluation tables and visualizations
- `notebooks/`: exploratory analysis
- `docs/`: project report and presentation placeholders

## Setup

Create and activate a virtual environment, then install dependencies:

```text
pip install -r requirements.txt
```

Place a labeled CSV at `data/train.csv`. It should include one or more text columns (`title`, `text`, or `subject`) and a `label` column.

## Usage

Run the entry point:

```text
python main.py
```

Train the models:

```text
python -m src.train
```

After training, use `src.predict.predict()` with a news article. Saved binary model files are generated in `models/`; reports are generated in `reports/` by the evaluation and visualization workflows.

The CSV, model, image, DOCX, and PPTX files included in the scaffold are placeholders. Replace them with real datasets and generated artifacts.
