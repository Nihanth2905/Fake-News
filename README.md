# 📰 AI-Powered Fake News Detection

An AI-powered web application that detects whether a news article is **Real** or **Fake** using **Machine Learning** and **Natural Language Processing (NLP)** techniques.

The application uses **TF-IDF Vectorization** for feature extraction and **Random Forest Classifier** for prediction. The trained model is deployed using **Flask** and hosted on **Render**.

---

# 📌 Project Overview

Fake news has become a major challenge on the internet. This project automatically classifies news articles as **Real News** or **Fake News** using Machine Learning.

The project follows the complete Machine Learning pipeline:

- Data Collection
- Data Preprocessing
- Feature Extraction
- Model Training
- Model Evaluation
- Web Application Development
- Deployment

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Nihanth2905/Fake-News.git
```

Move into the project

```bash
cd Fake-News
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
